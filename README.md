# משחק הכותל (Kotel Game): playable build

Mission 1, the Selichot night, in the browser:
**https://shayapps.github.io/kotelgame-play/**

- A desktop browser with a keyboard and mouse. Chrome or Edge renders with WebGPU; other
  browsers fall back to WebGL 2 (add `?webgl` to the address to force it).
- About 40 MB to load. Graphics presets (low / medium / high / ultra) are in Settings.
- Asset credits and licenses: in the game (Credits) and in `assets/CREDITS.md`.

This repository holds only the built game.
